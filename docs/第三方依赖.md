# 第三方依赖

网页依赖随项目提供，日常使用无需从网络下载或安装。

| 依赖 | 用途 | 许可证 |
| --- | --- | --- |
| SheetJS | Excel 解析和生成 | web/vendor/SheetJS-LICENSE.txt |
| JSZip | Excel OOXML、备份 ZIP 读写 | web/vendor/JSZip-LICENSE.md |

Windows PowerShell、.NET 文件与 DPAPI 能力使用 Windows 自带组件。开发检查使用 Node.js 原生模块，无额外 npm 包。GitHub 自动检查使用 actions/checkout 与 actions/setup-node。
