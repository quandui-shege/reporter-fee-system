# 华工学生记者团稿费 Agent

双击“启动系统.cmd”使用，请等待左下角显示“已保存到数据文件夹”后关闭。

## 查看与名单

选择单个月份，实际保存和查看对应固定双月周期：10、11月均为10–11月；1月为上一年12月–当年1月。
名单仅需姓名、部门，老师不加入；每页10人，可筛选、搜索、复制上期名单。同名须明确身份，关联已登记稿费的成员不能直接删除。

## 官微稿费

点击“新建项目”，先粘贴分工原文，再填写日期、官微标题、阅读量和原创状态，查看计算后保存。
“文”对应文字、“图”对应图片，续行沿用上一行分工；统筹对应策划，最多3人；微信编辑按确认的原创性质计费。初审、复审、终审不计费。
只有本周期名单内、身份明确的人员参加均分。原文完整保留到统计表“参与人员”列，名单外人员不会加入计算分母。
新增小项可直接输入“小项名称：张三 李四”。未知标签不猜金额，同名在匹配结果中手动选择。
所有官微小项固定均分，不能修改比例；文字、图片默认各100元，策划30元，原创编辑30元，非原创编辑15元，整理15元；海报、壁纸、尾图制作合为100元一项，可视化设计、H5制作、手绘合为150元一项。视频在视频组登记。
各小项先均分、截断，再累加到个人；保留一位，只舍不入，恰为.25的小数保留两位。奖励按去重后的参与人均分。原标准写“高于”，本系统按已确认的“达到门槛”执行，只取最高档。
页面与官微Excel统一六列：日期、官微标题、参与人员、阅读量、稿费、总稿费。稿费逐项列姓名和实际金额；总稿费按实际发放求和，例如100元分3人为33.3*3＝99.9元，不补尾差。Excel总稿费为公式，页面仅显示金额，导出Excel保留计算公式。

## 微博组稿费

导入已有Excel，在所有工作表查找相邻“人员”“稿费”表头，仅取下方人员汇总；底部合计不计入，不重算原表项目。
预览中匹配本周期名单，同名可选择身份；未匹配人员默认不计入。确认后按原表金额直接加到成员基础稿费，细则注明文件名，例如“微博组6月稿费”。同周期同名文件不能重复入账；需更新时先移除旧记录再导入。

## 小红书校报稿费

点击“新增稿费”，选择类别“小红书”或“校报”，选择当前双月周期内的具体月份，搜索并选择名单同学，填写金额后保存。
直接计入所填金额，不再分配或截断；细则分别显示“小红书10月稿费”“校报10月稿费”。

## 视频组稿费

页面分为“视频组稿费”和“视频稿费”，都支持新建项目、Excel导入、独立导出、分页及批量移除。
视频组活动填写活动名称、参与拍摄人员、活动时长（小时），可选日期；两小时内每人50元，超过两小时的部分每小时另补22.2元。可导入活动统计表，识别活动名称、时间、人员和时长，上午、下午保留为不同场次。
视频制作按每秒1元计算基本工资。岗位比例为策划/负责人20%、脚本10%、剪辑20%、配音10%、拍摄30%、场务灯光妆造模特10%；兼任累计，空缺岗位份额按制作人员去重均分。
视频绩效奖励不区分原创：播放量达到10000、30000、50000、100000、150000、200000，分别奖励30、100、150、200、300、400元，只取最高档，由制作人员去重均分。
两类导入预览均支持全部选择、取消选择、逐项移除和批量移除；移除需要确认。确认导入只计入勾选的有效项目。各自的“导入记录”可按文件查看人员与状态，未匹配者保留在导入记录、不计入外部稿费列表。移除整份导入后删除对应稿费和导入记录，不保存上传的原始Excel。
导出按参考表格布局，视频总工资＝基本工资＋绩效奖励；个人实发另按现有截断规则汇总，Excel保留计算公式。修改规则后同步重算所有周期。

## 规则、细则与备份

规则入口分官微、视频；官微内部为基本工资、绩效奖励，各自右上角提供选择、移除和新增按钮，移除确认一次。
修改规则金额立即重算所有周期的个人稿费、细则、预览与导出；微博、小红书、校报的直接金额不受官微视频规则影响。
个人细则可按全部、官微、视频、微博、小红书/校报筛选，注明作品和来源。移除作品或登记记录会同步重算。
没有待核对页面；未保存表单不计入金额。旧草稿仅保留在备份的历史归档中。
“导出与备份”提供个人汇总及明细Excel、全部周期备份和恢复。独立稿费包拒绝绩效数据包。数据保存在“数据/周期存档”，导出在“数据/输出/导出表格”。复制整个程序文件夹可迁移电脑。

成员选择统一弹窗：直接显示全部名单，每页10人，右上角按姓名搜索，点姓名即选中，不显示身份编号。
总导出无需选择部门，参照“记者团6.7月稿费(终版）”输出官微稿费、微博组稿费、视频组稿费、视频稿费、小红书稿费统计及工作明细；不导出代领名单和终版。微博保留导入原表并按两个月并排展示，另计双月实际总额。小红书与校报分两张姓名金额小表显示。微博、小红书校报页面亦支持单独导出总表对应部分。


## 列表与预览操作
个人汇总每页10人，支持全选、选择本页和批量移除；关联作品或复核人员的成员不能删除。官微统计每页5件作品，微博组和小红书校报每页8条，均支持跨页选择和批量移除，执行前确认一次。批量移除后个人汇总与导出同步更新。微博组和小红书校报列表不再显示细则按钮，可在个人汇总查看细则。
官微新建项目的预览最多显示5人，超出后在表格内滚动。分工可调整并立即重算；单个或批量移除后进入本项目复核，选择分工后可单个或批量算入。识别到名单内但不明分工的人员进入复核，名单外人员不计入。
微博导入记录保存每个文件原表人员，包括未匹配与移除人员；外部列表只展示计入稿费的记录。关闭下级弹窗只返回上一级，保留上一级操作内容；关闭最上一级后回到页面。

微博工具栏的“新增稿费”可按当前周期中的具体月份、名单成员和金额登记单笔稿费，金额直接计入个人汇总、工作明细和微博导出。手动登记不产生虚构的导入文件记录。
普通操作成功提示不再显示条幅，无法继续操作或错误信息改为独立提示弹窗；“知道了”只关闭提示，不关闭原表单。移除整个微博导入后，该文件不再显示在导入记录中，自动清除其人员与原表快照；用户原位置的Excel文件不受影响。

官微分工“运营”对应“整理”，共用整理规则金额，名单内参与人员去重后均分。

需要移动程序文件夹前，点击右上角“使用指南”右侧的“退出系统”。系统完成保存后停止后台，页面显示已退出。保存失败时不会退出，可重试。再次使用双击“启动系统.cmd”；重复启动复用后台，避免多个进程占用同一文件夹。

新启动系统默认进入“个人稿费汇总”；刷新保留所在功能的第一页。各稿费页面在批量操作栏右侧显示所选完整周期的总金额，翻页不改变总额；小红书与校报分别统计。

API Key设置显示“已填写并保存 / 未填写”状态。每个程序文件夹单独保存Key，使用当前Windows用户的加密保护；再次打开自动读取，点击“清除 Key”同时删除本地保存文件和当前使用的Key。稿费备份、表格导出不包含Key。

## 传输与分享

分享周期旁实时显示对应双月周期，选择7月对应6–7月，选择1月对应上一年12月–当年1月。旁边的“选择分享内容”弹窗一次选择一个稿费类别，已选内容显示在按钮右侧。导出的JSON分享文件可传到其他电脑，点击“导入分享文件”合并项目。
同一周期可接收多人、多个电脑分别统计的项目，保留本机已有项目。按项目编号、链接以及名称与日期等识别重合，活动上午下午为不同场次。重合超过2个项目时提供“取消导入”“删除重合部分再导入”“直接导入”：删除重合部分指跳过传入文件中的重合项目、保留本机已有项目；直接导入保留重合项目，相关稿费会重复计入。重合在2项以内默认跳过，避免重复计款。
来源项目的计算规则、人员身份和原Excel导入记录随分享文件保留；不同电脑金额一致，API Key不在分享文件中。分别导入A和B的数据后，可以在C查看合并后的个人汇总。
“导入记录”按导入批次显示例如“2026年6-7月 微博组稿费”，每页10条，可单项或批量移除，移除前再次确认。只清除该批传入的项目，其他批次和本机自建项目保留；其他项目使用的成员继续保留。
界面取消“本地保存”卡片，自动保存机制继续运行。普通刷新停留当前侧边栏功能的第一页；稿费规则刷新回到类别选择；新启动系统默认进入个人稿费汇总。
视频稿费在侧边栏独立显示，新建视频不填写平台或链接，日期必填。两类视频Excel导入都读取日期并可在预览中修改；视频项目标题显示“日期 · 项目名称”。视频表单和导入预览的红字校验隐藏，提交有问题通过提示弹窗显示。


导出表格沿用“记者团6.7月稿费(终版）”中视频组稿费、视频稿费的布局，项目行按 Excel 列顺序写入，日期显示保留上午/下午，个人金额与系统实发金额一致。修正前已导出的文件需要重新导出。微博组按钮顺序为“导入记录、新增稿费、导入微博稿费表、导出微博组稿费统计表”。分享文件导出前填写导出人姓名，文件名同时包含周期、稿费类别和姓名。


## 新目录与发布版
空白模板在 templates；待导入文件可放在 数据/输入；输出文件在 数据/输出。发布版无原稿费数据及 API Key。网页、后台和测试分别位于 web、server、tests。视频两张导出表为白底且不显示旁侧规则。
