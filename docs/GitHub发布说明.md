# GitHub 发布说明

## 已整理的内容

本目录是完整仓库根目录，包含可运行代码、空白模板、虚构测试样例、说明及自动检查。没有复制旧系统“数据”、后台运行标识、API Key、原始成员文件、历史导出、原始参考 Excel、培训文档或演示文件。旧版独立保留。

`.gitignore` 排除所有运行数据，只保留目录说明和 .gitkeep。发布扫描会拒绝运行数据、密钥文件、运行标识、密钥字串及个人绝对路径。密钥测试使用明确的虚构占位值，测试在临时副本执行。

## 发布前

```text
npm run audit:release
npm test
npm run test:integration
git status --short
```

最后检查待提交列表：只能出现代码、说明、空白模板、依赖和虚构测试文件。已经运行过系统后，应将数据留在本机；不要使用 git add -f 绕过忽略规则。若需要无个人数据的发布 ZIP，从 Git 已提交的文件导出归档。

本地 Git 仓库已初始化，但没有创建远程仓库、上传或推送。创建自己的 GitHub 仓库后，将这里的文件提交并连接远程地址即可。Windows GitHub Actions 会自动运行发布扫描、功能检查和临时副本集成检查。

## 维护

改动金额、导入或分享逻辑后运行全部检查。调整目录时同时更新 index.html、后台静态资源根目录和 tests 中的路径。空白输入模板由 scripts/create-templates.cjs 生成；虚构检查样例由 tests/fixtures/generate.cjs 生成。

## 旧数据迁入

在旧版通过“导出与备份”导出备份或特定部分的分享文件，在新版选择恢复/导入。已有人员身份、规则、日期和导入记录沿用原格式。API Key 不自动迁入，在新版另行填写；“清除 Key”仍删除新目录中的本地 Key。
