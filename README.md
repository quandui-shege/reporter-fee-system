# 华工学生记者团稿费统计系统 v2

在 Windows 电脑本地运行的记者团稿费统计工具。无需安装 Node.js 或 Python，双击 **启动系统.cmd** 即可打开浏览器。手动登记、Excel 导入、计算、导出及分享均可离线使用；AI 识别需要自己的 DeepSeek API Key 和网络连接。

## 开始使用

1. 下载整个项目并解压，保留目录结构；不要单独打开 web/index.html。
2. 双击启动系统.cmd，首次进入“个人稿费汇总”。
3. 选择月份和对应双月周期，添加成员或用 templates/成员名单模板.xlsx 导入名单。
4. 在对应页面登记官微、视频组活动、视频制作、微博、小红书或校报稿费。
5. 导出 Excel 或分享文件；移动文件夹前点击右上角“退出系统”。

这是干净发布版本，**不包含既有 API Key、成员名单、稿费、导入记录或个人输出文件**。旧版存档如需迁入，由使用者在旧版导出备份或分享文件，再在新版导入；密钥需重新设置。每个项目文件夹各自保存数据。

## 目录

| 目录 / 文件 | 用途 |
| --- | --- |
| 启动系统.cmd | 普通用户唯一启动入口 |
| web/index.html | 网页入口和界面骨架 |
| web/js/ | 计算引擎、界面、导入、导出和分享模块 |
| web/css/ | 界面样式 |
| web/assets/ | 无个人数据的导出布局和团徽 |
| web/vendor/ | 随项目提供的第三方库及许可证 |
| server/ | Windows 本地服务、文件保存及密钥管理 |
| templates/ | 四份空白输入模板 |
| 数据/输入/ | 可选存放待导入 Excel 或分享文件 |
| 数据/输出/导出表格/ | 系统生成的 Excel |
| 数据/输出/备份数据/ | 系统生成的备份及分享文件 |
| 数据/周期存档/ | 自动保存的周期数据 |
| tests/ | 自动检查和虚构测试样例 |
| scripts/ | 开发检查、模板生成工具 |
| docs/ | 架构、使用和发布说明 |

输入文件仍通过文件选择器读取，不自动复制原文件；导出文件既写入输出目录，也提供浏览器下载。API Key 加密保存在“数据/.deepseek-key”，清除 Key 会删除本地文件，备份与分享不包含 Key。

## 功能

八个侧边栏入口：个人稿费汇总、官微稿费、视频组稿费、视频稿费、微博组稿费、小红书校报稿费、导出与备份、稿费规则。保留周期管理、成员选择、单项与批量操作、导入预览与记录、金额和分工计算、规则修改、Excel 导出、备份恢复、跨电脑分享合并、重合提醒、刷新保留页面及退出系统。

详见 [使用指南](docs/使用指南.md)、[系统架构](docs/系统架构.md) 和 [GitHub 发布说明](docs/GitHub发布说明.md)。

## 开发与检查

仅开发和运行测试需要 Node.js 20 或以上。第三方网页依赖已随项目提供，无须 npm install。

```text
npm test
npm run test:integration
npm run audit:release
```

功能检查覆盖金额规则、导入导出、备份分享、批量移除及日期。集成检查仅在临时目录建立虚构数据副本，验证本地启动、保存、输出路径、密钥隔离、重启和退出，结束后清理测试文件。
