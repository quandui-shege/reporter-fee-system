记者团稿费统计系统 v2

1. 请保留完整目录，双击“启动系统.cmd”打开系统。
2. 首次使用没有历史成员、稿费或 API Key，请先设置周期并录入名单。
3. 空白输入模板在 templates 文件夹。
4. 待导入文件可放在“数据/输入”，也可直接从其他位置选择；系统不自动复制原文件。
5. Excel 导出在“数据/输出/导出表格”；备份和分享在“数据/输出/备份数据”。
6. 稿费自动保存到“数据/周期存档”；API Key 在本目录单独加密保存。
7. AI 识别才需要 API Key；手动登记、Excel 导入与计算可离线使用。
8. 清除 Key 会删除本地 Key。备份与分享不包含 Key。
9. 移动文件夹前请点击“退出系统”，等待后台退出。
10. 上传 GitHub 前查看 docs/GitHub发布说明.md；不要上传本机数据。
